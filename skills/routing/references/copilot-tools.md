# Tool equivalents by surface

Skill text uses Claude Code tool names. Find the session's surface below and use its table to translate each name. A
surface with no table detects tools by presence: use a tool only when the session lists it, and never use another
surface's table. A row that says "detect by presence" means the same check.

## Copilot CLI

Checked against GitHub Copilot CLI 1.0.109 on 2026-11-12, read from the installed build with no model run.

| Claude Code tool            | Copilot CLI equivalent                    | Notes                                                                                                                                                                                                                                                                                                                                                                      |
| --------------------------- | ----------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Read`                      | `view`                                    | Reads files.                                                                                                                                                                                                                                                                                                                                                               |
| `Edit`                      | `edit`                                    | Makes string replacements in files.                                                                                                                                                                                                                                                                                                                                        |
| `Write`                     | `create`                                  | Creates a new file only. `create` refuses a path that already exists, so it does not overwrite. Change an existing file with `edit`.                                                                                                                                                                                                                                       |
| `Bash`                      | `bash` or `powershell`                    | The CLI registers both names. Which one a session has is not shown. Detect by presence.                                                                                                                                                                                                                                                                                    |
| `Glob`                      | `glob`                                    | Finds files by glob pattern.                                                                                                                                                                                                                                                                                                                                               |
| `Grep`                      | `grep`                                    | Searches file contents with ripgrep. The tool can also be named `rg`.                                                                                                                                                                                                                                                                                                      |
| `WebFetch`                  | `web_fetch`                               | Fetches a URL and returns the page as Markdown or raw HTML.                                                                                                                                                                                                                                                                                                                |
| `WebSearch`                 | `web_search`                              | Behind a feature flag, so a session may not have it. Detect by presence.                                                                                                                                                                                                                                                                                                   |
| `Skill` (skill invocation)  | `skill`                                   | Invoke by name.                                                                                                                                                                                                                                                                                                                                                            |
| `Agent` (subagent dispatch) | `task` (`agent_type`)                     | Dispatch a general-purpose subagent.                                                                                                                                                                                                                                                                                                                                       |
| `TodoWrite`                 | `update_todo`, else `sql` + `todos` table | Use `update_todo` when the session has it. Otherwise Copilot's task list is a table in the per-session SQLite database: write to it. Detect by presence. `update_todo` is source-observed in the Copilot CLI 1.0.109 build (2026-11-19). A 1.0.109 `copilot -p` session on 2026-11-19 had no `update_todo` and had the `sql` tool with the `todos` and `todo_deps` tables. |
| `TaskCreate` / `TaskUpdate` | `update_todo`, else `sql` + `todos` table | Same preference as `TodoWrite`. In the table, `INSERT` adds a task and `UPDATE` changes its state.                                                                                                                                                                                                                                                                         |
| `AskUserQuestion`           | `ask_user`                                | A question to the user. A session started with `--no-ask-user` does not have it. On Copilot, `decompose` asks its approval question through it.                                                                                                                                                                                                                            |

## Codex

Checked against codex-cli 0.167.2 on 2026-11-12, read from the installed build with no model run.

| Claude Code tool            | Codex equivalent             | Notes                                                                                                                                        |
| --------------------------- | ---------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| `Read`                      | none verified                | No dedicated file-read tool was found. `view_image` inspects a local image. Detect by presence.                                              |
| `Edit`                      | `apply_patch`                | Edits files.                                                                                                                                 |
| `Write`                     | `apply_patch`                | Same tool as `Edit`.                                                                                                                         |
| `Bash`                      | `exec_command`               | The shell tool's name depends on configuration. Detect by presence.                                                                          |
| `Glob`                      | shell + `rg --files`         | Codex's instructions prefer `rg --files` for finding files.                                                                                  |
| `Grep`                      | shell + `rg`                 | Codex's instructions prefer `rg` for searching text.                                                                                         |
| `WebFetch`                  | none verified                | No page-fetch tool was found. Detect by presence.                                                                                            |
| `WebSearch`                 | `web_search`                 | Available only when live web search is enabled (`--search`). Detect by presence.                                                             |
| `Skill` (skill invocation)  | none verified                | Detect a skill tool by presence. Without one, use a skill by reading its `SKILL.md` completely. The user invokes one explicitly as `$skill`. |
| `Agent` (subagent dispatch) | `spawn_agent` (`agent_type`) | Spawning needs permission first. See **Dispatch permission** in [surface-dispatch.md](surface-dispatch.md).                                  |
| `TodoWrite`                 | `update_plan`                | Takes `plan`, a list of steps that each have `step` and `status`.                                                                            |
| `TaskCreate` / `TaskUpdate` | `update_plan`                | Same tool.                                                                                                                                   |
| `AskUserQuestion`           | `request_user_input`         | One to three short questions. Present only in some turns. Detect by presence.                                                                |

## VS Code and Cursor

These surfaces have no table. Detect tools by presence.
