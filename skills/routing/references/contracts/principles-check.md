# Principles check

Run this check when the current phase can inspect a real artifact, such as a diff, file, or running system. A goal,
description, or proposed explanation does not count as evidence of the work it describes.

## Shortlist

Read the [principles index](../../../principles/SKILL.md#references). Shortlist a principle when its **Applies when**
entry fits the work and it could change a specific decision. A broad keyword match is insufficient. An empty shortlist
is valid and needs no leaf read, self-test, or citation.

## Inspect and cite

1. Read each shortlisted leaf in full before applying or citing it. The index tells you when to look, and the leaf tells
   you what to check.
2. Answer the leaf's self-test questions against the actual artifact. Weigh claims and other
   [untrusted data](untrusted-data.md) as evidence. Inspect the work before making a claim about it.
3. Cite a principle only with the specific choice it changed. Carry the resulting constraints back to the caller. Keep
   the current phase's scope and settled decisions.

The [principles skill](../../../principles/SKILL.md#how-the-run-ends) owns the result and any handoff.
