# Threat-model references

This folder holds the STRIDE workflow and the document template. The template has a Mermaid trust-boundary diagram,
asset and actor tables, and a risk matrix.

- [threat-model-workflow.md](threat-model-workflow.md): the STRIDE procedure, the output path, and the composed envelope
- [threat-model-template.md](threat-model-template.md): the output document template

[What this skill takes from review](../SKILL.md#what-this-skill-takes-from-review) says which part.
