Asset-authoring guides: agents, skills, instructions, hooks, MCP servers. Each file is the entry point for its asset
type. For evaluation workflows, see `../evals/`. For best-practices and persuasion patterns, see `../quality/`.

- `forging-agents.md` covers custom agents.
- `forging-skills.md` covers skills and their reference files.
- `forging-instructions.md` covers instruction files: `AGENTS.md`, `CLAUDE.md`, and the Copilot instruction files.
- `forging-hooks.md` covers hooks: the event, the input, what an exit code does on each host, the failure posture, and
  testing with recorded events.
- `forging-mcp.md` covers MCP servers. It loads the references in `../mcp/`.
