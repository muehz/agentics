# Templates

File templates: README, ARCHITECTURE, CHANGELOG, issue templates, PR template.

For staged and CI secret-scan examples for Husky, Lefthook, and pre-commit consumers, see
[secret-scans.md](secret-scans.md).

For separately selected consumer permissions, secret-read denies, sandbox/network options, post-edit checks, protected
paths and explanatory blocks, see [consumer-settings.md](consumer-settings.md). These are guidance and preview
requirements for the consumer's configuration. They add no active Agentics runtime hooks or settings.

For governance/community files, see [`../governance/`](../governance/) or [`../community/`](../community/).

> Note: the README template is named `readme-template.md`, not `readme.md`, to avoid a case-insensitive collision with
> this folder index on macOS/Windows filesystems.
