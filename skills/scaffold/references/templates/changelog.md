# Scaffold reference: CHANGELOG.md

## Questions to ask

None. Generate a standard initial file.

## Initial content

```markdown
# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]
```

## Notes

- Do not add release entries. The first release will populate them.
- If the project uses `release-please`, it writes future entries
- If the project uses a different changelog tool, note that in the preview

## Conformance check (audit mode)

✅ Conformant if the file exists and is non-empty.
